# 接客記録・連絡リマインドシステム（サンプル）

クラブなど接客業向けの、来店記録の管理と連絡タイミングのリマインドを行うWebアプリのサンプルです。スマホのメモアプリで管理していた来店記録を、スマホから入力してGoogleスプレッドシート上で自動管理できるようにします。

実際に使っているツールから、お客様・お店・スタッフの情報と鍵を取り除いて公開しています。
**`SPREADSHEET_ID` を設定せずに起動すると、作り物のデータで動く「見本」になります**（本物のスプレッドシートにはつながりません）。

## 見本として動かす（いちばん簡単）

```bash
pip install -r requirements.txt
python wsgi.py
```

http://127.0.0.1:5000 を開くと、ログインなしで、架空のお客様・来店記録・予定が入った状態で使えます。
入力した内容はパソコンのメモリーの中だけに残り、起動し直すと最初の状態に戻ります（`src/sample_sheets.py`）。

## 概要

- 来店したその場でスマホから記録を入力すると、システムが自動でお客様ごとに情報を集約する
- 「最終連絡日＋連絡頻度日数」を超えたお客様と、誕生日が近いお客様を毎日自動で判定して表示する
- データの保存先はGoogleスプレッドシート。特別なデータベースを用意する必要がない
- Vercelにデプロイ済みで、スマホのホーム画面に追加すればアプリのように使える

## 画面

| 画面 | 内容 |
|---|---|
| リマインド | 今日連絡すべき客・誕生日が近い客を表示 |
| 入力 | 来店記録の入力。未記録の予定があれば上部に表示 |
| 顧客一覧 | 自客・係ごとのタブ表示、名前検索 |
| カレンダー | 共通予定（強制同伴日・イベント等）と個人の予定 |
| 実績 | 期間の売上・同伴実績、月ごとの推移グラフ |

## 技術スタック

| 分類 | 技術 |
|---|---|
| 言語 / フレームワーク | Python 3.9, Flask |
| データ保存 | Google スプレッドシート（Google Sheets API） |
| 認証 | パスワードのハッシュ化（werkzeug, pbkdf2:sha256）をスプレッドシート上で管理 |
| デプロイ | Vercel（Serverless Functions / @vercel/python） |
| バージョン管理 | GitHub |
| テスト | pytest |

## 主な機能

- **今日のリマインド**：連絡すべき客・誕生日が近い客を毎日自動判定して表示
- **来店記録の入力**：自客・他客を分けて入力。同伴の有無・同伴者・売上なども記録
- **顧客一覧・検索**：自客／係ごとのタブ表示、名前検索、来店履歴の確認
- **顧客詳細**：会社名・役職・誕生日・プロフィールメモを管理
- **来店記録の修正**：月ごとのタブ表示から過去の記録を見つけて修正
- **カレンダー**：強制同伴日・イベント等の共通予定と、同伴・来店の個人予定を管理
- **実績**：期間ごとの売上・同伴実績、月次推移グラフ、過去の実績の閲覧
- **設定**：期間の切り替え、係（スタッフ）の管理、パスワード変更、テーマ切り替え

## 使い方

### アプリを使う（日々の利用）

1. デプロイ先のURLをSafari等で開く（スマホの場合は共有ボタンから「ホーム画面に追加」しておくと便利）
2. パスワードでログイン
3. 来店したら「入力」画面からその場で記録
4. トップの「リマインド」画面で、その日連絡すべき客・誕生日が近い客を確認

### 本物のスプレッドシートにつないで使う

```bash
# 依存関係のインストール
pip install -r requirements.txt

# サービスアカウントの認証情報を配置
# credentials/service_account.json

# 環境変数を設定
export FLASK_SECRET_KEY="任意の文字列"
export APP_PASSWORD="初回ログイン用の初期パスワード"
export SPREADSHEET_ID="対象のスプレッドシートID"

# テストを実行
pytest

# ローカルで起動
python wsgi.py
```

### デプロイ（Vercel）

VercelにはRenderの「Secret Files」のようなファイル配置機能がないため、サービスアカウントの認証情報はファイルではなく環境変数（JSON文字列）で渡す。

1. GitHubリポジトリをVercelにインポートする（New Project → Import Git Repository）
2. Vercelプロジェクトの Settings → Environment Variables に以下を設定する

   | 変数名 | 値 |
   |---|---|
   | `FLASK_SECRET_KEY` | 任意の文字列 |
   | `APP_PASSWORD` | 初回ログイン用の初期パスワード |
   | `SPREADSHEET_ID` | 対象のスプレッドシートID |
   | `GOOGLE_CREDENTIALS_JSON` | `credentials/service_account.json` の中身をそのまま1行のJSON文字列として貼り付け |

3. Deployを実行するとURLが発行される（`https://<プロジェクト名>.vercel.app`）
4. 以後はGitHubの対象ブランチにpushすると自動で再デプロイされる

ローカル開発時は従来どおり `GOOGLE_CREDENTIALS_PATH`（ファイルパス）が使われる。`GOOGLE_CREDENTIALS_JSON` が設定されている場合はそちらが優先される。

## プロジェクト構成

```
src/            集計・リマインド判定・検索などのコアロジック（Flaskに依存しない）
  models.py       データ構造の定義
  sheets_client.py  Google Sheets API連携
  sample_sheets.py  見本用の作り物のスプレッドシート（SPREADSHEET_ID が無いときに使う）
  aggregate.py    日次入力の顧客マスタへの集約
  reminder.py     リマインド・誕生日判定
  search.py       来店履歴の検索
  reports.py      期間・月次集計
webapp/         Flaskアプリケーション
  routes.py       画面のルーティング
  auth.py         ログイン認証
  templates/      画面テンプレート
  static/         CSS
tests/          pytestによる単体テスト
```
